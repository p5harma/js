Privacy policy

Last updated: October 20, 2026

js is a personal tool run by Pranav Sharma on his own computer, for his own use. It has no other users.

Google user data accessed

With the account owner's permission, job-scanner uses the Google Drive API to find a folder in the owner's Google Drive, create subfolders in it, upload documents the owner generated, and read back the links to those documents.

How the data is used

Drive access is used only to store and organize the owner's own documents and to record their links in a local file on the owner's computer. js does not read, change, or delete any other files in Google Drive.

Storage and sharing

The Google authorization token is stored only on the owner's computer. No Google user data is sold, shared with third parties, used for advertising, or used to train machine-learning models. js's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
